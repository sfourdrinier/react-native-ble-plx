# ADR: Owned mobile radio + Electron multi-OS natives (4.0 GA)

**Status:** Accepted for 4.0 GA train  
**Date:** 2026-07-24  
**Branch:** `4.0`

## Context

4.0 GA requires (1) default mobile radio without RxAndroidBle/MBA, (2) Electron main-process natives on Linux BlueZ, Windows WinRT, macOS CoreBluetooth, (3) honest `supports()` and CI compile/test green.

## Decision 1 — Owned Kotlin Android GATT as default BleAdapter

| Persona | Opinion |
| ------- | ------- |
| A App | Transparent if JS API unchanged |
| B Perf | Removes Rx hop; bytes path can later skip copies |
| C Security | Fewer third-party BLE stacks |
| D Maintain | Large rewrite risk; keep BleAdapter interface stable |

**Choice:** `OwnedBleAdapter` + `OwnedAndroidGattRadio` (Kotlin) is factory default. Legacy `BleModule` (Rx) moves to `android/src/legacy` (not compiled). RxAndroidBle dependency removed from `android/build.gradle`.

## Decision 2 — Owned Swift CoreBluetooth as default iOS adapter

| Persona | Opinion |
| ------- | ------- |
| A App | Same ObjC bridge via BleAdapter protocol |
| B Perf | No RxBluetoothKit |
| C Privacy | Restoration stays opt-in subspec |
| D Maintain | Exclude MBA BleModule + Rx* from podspec sources |

**Choice:** `OwnedCoreBluetoothAdapter` implements `BleAdapter`; factory returns it; podspec excludes RxBluetoothKit/BleModule.swift.

## Decision 3 — Electron OS natives via BlePort + optional N-API

| Persona | Opinion |
| ------- | ------- |
| A App | One electron entry, OS-selected port |
| B Perf | Main process radio |
| C Security | No WebBT-in-renderer production |
| D Maintain | BlueZ real TS D-Bus port; WinRT/macOS addon stubs + Fake fallback + CI |

**Choice:** `BluezBlePort` (D-Bus) for Linux; `createWinRtBlePort` / `createCoreBluetoothBlePort` with native package placeholders and mock fallback for CI without addons. `createPlatformElectronPort()` async helper.

## Consequences

- Parity tests remain on JS BleManager + PortBleManager.
- Structural tests assert no RxAndroidBle dependency and factory/podspec cutover.
- BlueZ contract tests inject mock D-Bus.
- Device lab FGS/restore still L4 / env-limited on Linux.
