# 3.9.0 Gated ConnectionManager + Restored-State Handoff Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship additive 3.9.0 APIs: `ConnectionManager.attemptConnectOnce` (externally gated single connect) and `BleManager.getRestoredState` (buffered iOS restore handoff), with zero behavior change for existing dual-option restore callers and for all `connect` / auto-reconnect defaults.

**Architecture:** Feature 1 reuses `_attemptConnection` with `maxRetries` forced to `1` and a `gatedAttempt` flag. **Strict coalesce:** gated calls only join an in-flight attempt that is already gated (never silently inherit multi-retry `connect`). Feature 2 registers `RestoreStateEvent` whenever `restoreStateIdentifier` is set, buffers the **first** mapped payload, still invokes `restoreStateFunction` on **every** emit, and exposes a Promise that returns the buffer or waits for the first event.

**Tech Stack:** TypeScript `src/`, Jest `__tests__/`, existing `BleError` / `BleErrorCode`, docs under `docs/`, branch `feat/27-gated-cm-restored-state`. Issue: [#27](https://github.com/sfourdrinier/react-native-ble-plx/issues/27).

**Compatibility guarantee:** Auto mode remains default. Public `connect(...)` signature and defaults unchanged. `restoreStateFunction` still receives the same mapped shape and is still called on every RestoreStateEvent when provided. Dual-option constructor (identifier + function) behavior for the callback path is preserved. Identifier-only registration is an **additive** expansion (documented). No new package exports beyond methods on existing classes. Prefer no new `BleErrorCode` (`OperationStartFailed` + clear `reason`).

## Locked product decisions (from adversarial review)

### D1 — Gated coalesce (strict)

Issue AC says coalesce with in-flight connect; that conflicts with “exactly one attempt” if the in-flight call is multi-retry.

**Decision:** `attemptConnectOnce` may **only** coalesce when `existing.pendingPromise && !existing.cancelled && existing.gatedAttempt === true`.

| In-flight | `attemptConnectOnce` |
| --------- | -------------------- |
| None | Start gated attempt (`maxRetries: 1`, `gatedAttempt: true`) |
| Gated pending | Coalesce (same Promise) |
| Non-gated `connect` pending (any `maxRetries`) | **Reject** `OperationStartFailed` (do not join multi-retry) |
| Auto-reconnect enabled (idle or not) | **Reject** `OperationStartFailed` |

`connect()` while gated pending: **allowed to coalesce** onto the gated pending Promise (same as joining one native attempt). Document: joining a gated flight does not enable auto; `gatedAttempt` stays true until settle so `enableAutoReconnect` still throws.

### D2 — `getRestoredState` null / non-restore matrix

Runtime API remains `Promise<BleRestoredState | null>` (issue candidate). Full OS-level distinguishability is **not** always possible in JS; honest docs + the following closed table:

| Situation | Settles | Value | How app distinguishes |
| --------- | ------- | ----- | --------------------- |
| No `restoreStateIdentifier` | Immediate | `null` | App did not pass identifier; no wait |
| Identifier set, event not yet | Wait | — | Pending until first event or destroy |
| First event: native `null` | Yes | `null` | Restoration configured + “restored: nothing” / cold / Android null emit |
| First event: `{ connectedPeripherals: [] }` | Yes | that object | Empty list ≠ `null` if native sends empty array |
| First event: peripherals present | Yes | mapped `Device[]` | Restored devices |
| Subsequent events | Immediate (buffer) | **First** buffered value | Callback still fires every emit with **new** mapping |
| Android + identifier | Yes (native emits null promptly on createClient) | usually `null` | No CB restore; event is synthetic null |
| tvOS + identifier | May wait until destroy if no emit | destroy resolves waiters with `null` | Doc: do not use restore on tvOS; destroy/unmount cleans waiters |
| Restoration subspec off (iOS) + identifier | May wait until destroy | destroy → waiter `null` | Doc: install Restoration subspec / plugin flag |
| After `await destroy()` | Immediate | `null` | Manager dead; do not treat as restore payload |

**Product reinterpretation of issue F2.3:** “distinguishable” is achieved by (1) whether the app configured an identifier, (2) `null` vs non-null object vs empty `connectedPeripherals`, (3) documentation of platform limits—not by a multi-variant return type in 3.9.0.

### D3 — `enableAutoReconnect` error style

Keep **throw** `BleError` (sync API stays `void`). Document try/catch. `attemptConnectOnce` **rejects** (async). Asymmetry is intentional.

### D4 — Example scope

Task 6 is a **documented stub** (Platform.OS === 'ios' + `getRestoredState` log). Full restore plugin/Info.plist wiring is optional follow-up, not required to close #27 if docs + unit tests cover the contract.

## Grounded invariants (current code)

1. **`maxRetries`** = total attempts including first. `1` ⇒ one native connect, no retry timer.
2. **`connect` coalesce** mutates `pending.resolve`/`reject` chains (preserve exactly).
3. **`enableAutoReconnect`** re-arms on **any** disconnect including `null` error.
4. **`cancel`** bumps `attemptId`; if `!autoReconnect` deletes device entry.
5. **Restore listener today:** only if both identifier and function set; map then callback.
6. **Android:** `createClient` with non-null identifier emits `RestoreStateEvent` null (see `BleModule.java` / `BlePlxModule`).
7. **`destroy()` is async**; clears `sharedInstance` after `destroyClient`.
8. **Singleton:** first constructor options win; second `new BleManager(opts)` returns shared instance.

- [ ] **Step 2: Mechanical move of `connect` body**

1. Rename current public method body into `private _beginConnect(deviceId, options, mode: { gated: boolean })`.
2. Public:

```ts
connect(deviceId: DeviceId, options?: ConnectionOptionsWithRetry): Promise<Device> {
  return this._beginConnect(deviceId, options, { gated: false })
}

attemptConnectOnce(deviceId: DeviceId, options?: ConnectionOptionsWithRetry): Promise<Device> {
  return this._beginConnect(deviceId, options, { gated: true })
```

3. **Only gated deltas** inside `_beginConnect` (everything else is a cut-paste of current `connect`):

| Point | Non-gated (`connect`) | Gated |
| ----- | --------------------- | ----- |
| Pre-check auto | none | if `isAutoReconnectEnabled` → `Promise.reject(OperationStartFailed)` |
| Pre-check in-flight non-gated | n/a | if `existing?.pendingPromise && !cancelled && !existing.gatedAttempt` → reject `OperationStartFailed` |
| Coalesce | current chain | only if `existing.gatedAttempt` (same chain code) |
| `maxRetries` | `options?.maxRetries ?? 3` | always `1`; `console.warn` if `options?.maxRetries != null && options.maxRetries !== 1` |
| `autoReconnect` | `existing?.autoReconnect ?? false` | always `false` |
| `reconnectOptions` | preserve existing | `undefined` (or leave unused) |
| `disconnectSubscription` | preserve existing | do not steal auto sub: if somehow auto was true we already rejected; keep `existing?.disconnectSubscription` only when non-gated |
| `gatedAttempt` | `false` | `true` |

- [ ] **Step 2: Constructor listener**

```ts
const restoreStateIdentifier = options.restoreStateIdentifier
const restoreStateFunction = options.restoreStateFunction

if (restoreStateIdentifier != null) {
  this._activeSubscriptions[this._nextUniqueID()] = this._eventEmitter.addListener(
    BleModule.RestoreStateEvent,
    (nativeRestoredState: NativeBleRestoredState | any) => {
      const mapped: BleRestoredState | null =
        nativeRestoredState == null
          ? null
          : {
              connectedPeripherals: nativeRestoredState.connectedPeripherals.map(
                (nativeDevice: any) => new Device(nativeDevice, this)
              )
            }

      if (this._restoredState === undefined) {
        this._restoredState = mapped
        const waiters = this._restoreStateWaiters
        this._restoreStateWaiters = []
        for (const resolve of waiters) resolve(mapped)
      }

      if (restoreStateFunction != null) {
        restoreStateFunction(mapped)
      }
    }
  )
} else {
  this._restoredState = null
}

BleModule.createClient(options.restoreStateIdentifier || null)
```

**Order:** register listener **before** `createClient` (Android may emit on create).

```ts
async getRestoredState(): Promise<BleRestoredState | null> {
  if (this._restoredState !== undefined) {
    return this._restoredState

  return new Promise((resolve) => {
    this._restoreStateWaiters.push(resolve)
  })
}
```
