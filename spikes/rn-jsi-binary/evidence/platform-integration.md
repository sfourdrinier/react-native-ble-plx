# Platform integration evidence

This register intentionally separates replayed commands from untested surfaces. It covers the isolated owned JSI binary transport only; it does not claim a physical BLE radio, background execution, restoration behavior, Expo behavior, or a production package feature. The containing example legitimately declares `bluetooth-central` for its separate restoration demonstration; the JSI transport neither depends on that declaration nor validates restoration.
